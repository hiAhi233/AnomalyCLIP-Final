# AnomalyCLIP-Gen：病灶聚焦分类 + 全图兜底 + 中文报告生成

## 一、架构总览（串行为主 + 双流兜底）

```
输入图像 [B, 3, 224, 224]
  │
  ▼
BiomedCLIP ViT ──► patch 特征 [B, 196, 768]
  │
  ▼
Path B: 记忆库异常检测（现有）
  │  → anomaly map [B, 14, 14]
  │  → s_img（图像级异常分数）
  │  → patch 级异常分数
  ▼
Path C: 病灶掩膜（现有）
  │  → mask = (anomaly map > 阈值) 上采样至 224
  │  → masked_image = image × (mask + α·(1-mask))   ← 突出病灶、抑制背景
  ▼
╔═══════════════ 双流分类（核心新增）════════════════╗
║  流1: masked_image ──► BiomedCoOp 分类 ──► logits_masked  ║
║        （病灶聚焦，主力）                              ║
║  流2: 原图 ──► BiomedCoOp 分类 ──► logits_full       ║
║        （全图兜底，掩膜出错时保底）                     ║
║  共享 image encoder + prompt learner（参数不翻倍）      ║
╚══════════════════════════════════════════════════════╝
  │
  ▼
logits = λ·logits_masked + (1-λ)·logits_full
（λ 训练期 annealing: 0.5 → 0.8；掩膜不可信时自动回落）
  │
  ├──────────────────────────────────────────┐
  ▼                                          ▼
类别标签 + 可信度                      病灶聚焦视觉特征
  │                                  （masked_image 的 patch，
  │                                    可选 anomaly 加权）
  ▼                                          ▼
规则推导征象（报告期用）              MLC 征象分类头（9 征象多标签）
  │                                          │
  ▼                                          ▼
                                     Co-Attention（视觉+征象融合）
                                          │
                                          ▼
                                     SentenceLSTM → topic + p_stop
                                          │
                                          ▼
                                     WordLSTM → 中文词概率
                                          │
                                          ▼
                                     中文报告（Beam Search 推理）
```

## 二、双流分类细节

### 2.1 λ 的设计（关键）

```python
# 训练期：随 epoch 从 0.5 线性升到 0.8（掩膜质量随训练变好）
lam = min(0.8, 0.5 + 0.3 * epoch / MAX_EPOCH)

# 动态调节：掩膜不可信时回落（s_img 低 = 记忆库距离小 = 可能无病灶）
if s_img < 0.2:
    lam = min(lam, 0.3)   # 疑似正常图像，多信全图分类

# 推理期：固定 lam=0.7，或按 s_img 分档：
#   s_img ≥ 0.5 → lam=0.8（病灶明确，聚焦为主）
#   0.2 ≤ s_img < 0.5 → lam=0.6
#   s_img < 0.2 → lam=0.3（无病灶，全图为主）
```

### 2.2 双流共享参数（推荐）

```
共享: image encoder (ViT) + prompt learner (上下文向量)
双流: 同一 forward 跑两次，输入分别 masked_image / 原图
参数开销: 仅多一次 forward，无新增参数 → 小数据不过拟合
```

### 2.3 掩膜质量监控（防退化）

```python
# 每 epoch 统计：mask 平均激活比例（期望 5%~60%，全 0 或全 1 说明异常）
mask_ratio = mask.mean().item()
if mask_ratio < 0.01 or mask_ratio > 0.9:
    log_warning("掩膜退化，检查记忆库/阈值")
```

## 三、生成器细节（借鉴 Vinyals 2017 层级 LSTM）

### 3.1 模块结构

```
MLC:        9 征象多标签分类 → top-k 征象 → 征象语义特征 [B, k, 512]
CoAttention: 病灶聚焦视觉特征 v_att + 征象语义 → 上下文 ctx [B, 512]
SentenceLSTM: ctx → 句子主题 topic [B, 512] + p_stop [B, 2]
WordLSTM:    topic + 已生成词 → 下一词概率 [B, vocab_size]
```

### 3.2 中文词表（233 例报告构建）

```python
# build_vocab 流程:
#   233 例报告 → jieba 分词 → 词频统计 → 保留 top 2000
#   特殊 token: <pad> <sos> <eos> <unk>
#   词向量: 随机初始化训练（数据少，不用预训练）
```

### 3.3 训练监督（teacher forcing）

```
输入: 图像 + 报告词序列 [w1, w2, ..., wt]
监督: 预测 [w2, w3, ..., w(t+1)]
损失: CE(词) × 掩码（忽略 padding）
```

### 3.4 推理（Beam Search）

```
Beam k=3:
  外层 SentenceLSTM: 生成句子主题，p_stop 判断是否结束报告（s_max=8 句）
  内层 WordLSTM: 每句逐词生成（n_max=50 词）
  最终: 句子序列拼接 → 完整中文报告
```

## 四、损失函数（联合训练）

```
L = λ₁·CE(双流分类 logits)      # 分类
  + λ₂·CE(MLC 9征象)            # 征象多标签（标签从真实报告提取）
  + λ₃·CE(词生成, teacher forcing)  # 报告生成
  + λ₄·CE(p_stop)               # 句子停止判断
  + λ₅·L1(s_img, 分类异常概率)   # 异常一致性（现有 LAMBDA_CONSIST）
  + λ₆·KDSP + λ₇·SCCM           # 现有 BiomedCoOp 蒸馏/一致损失

典型权重: λ₁=1.0  λ₂=0.5  λ₃=1.0  λ₄=0.5  λ₅=0.5  λ₆=0.75  λ₇=0.75
```
