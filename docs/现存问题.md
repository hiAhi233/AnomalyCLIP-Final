# 现存问题清单（2026-08-16）

## 1. CLIP 视觉主干能否学会"看纵隔占位"——未决

**问题**：预训练 BiomedCLIP 对 11 类前纵隔占位无判别力（冻结特征 5 折 CV 16.8% ≈ 随机 9%；
文本原型两两相似度 0.65~0.92，退化）。487 张代表层微调 4 block 过拟合（train 78% / test 20-28%；
二分类 F1 ~55%）。

**未决实验**：全部 10 层（~7000 张）+ LoRA r=8 全注意力层 + 正则（weight decay/早停）。
这是"CLIP 能否获得该任务判别力"的唯一未做实验（~1-2 小时）。

**影响**：若学会 → 报告视觉词元/Path B/定位全受益；若学不会 → 论文如实写
"预训练 VLM 在此任务的局限 + 征象融合的必要性"（本身是方法学发现）。

## 2. 报告尺寸数字的精确注入——方案已定未实施

**问题**：19 维征象穿 MLP 连续投影有损，尺寸数字失真（真实 18mm → 生成 43mm）。
**方案（混合式）**：尺寸（长径/短径）以**文字 token** 注入输入序列（离散无损，模型照抄）；
其余类别型征象（强化/钙化/密度）保留 **MLP 征象词元**（已验证 CE 0.31 / ROUGE 0.4）。
**成本**：热启动续训 3-4 轮（现有检查点参数结构不变，直接 INIT_WEIGHTS）。

## 3. Path B 定位质量——同域验证未做

**现状**：跨批次验证检测 AUC 0.902（强）；定位命中率 8.8%（argmax 被域偏移离群点抢走）。
**对策（待做）**：同域留出法（233 例 ROI 数据自建库，100 建库/133 验证）+ 聚类定位
（最大连通高分区质心）+ 度量改"质心距离"。

## 4. CE 期望向量的粗糙度

**现状**：CE-F1 0.31（P=0.43 R=0.29）。recall 偏低部分源于标签级期望向量（按病种平均，
如胸腺瘤期望"钙化=1"但多数胸腺瘤无钙化）。
**改进方向**：期望向量按病种细化（必有征象=+1，可有可无=0 中性）。

## 5. 分类头尚未并入主模型

**现状**：结构化特征分类器（二分类 79.1% / 11 类 56.5%）是独立脚本
（train_structured_classifier.py），未整合进 AnomalyCLIP。提示词分类腿已证明无效（acc ≈ 多数类基线），
计划退役，由征象分类头取代（可选 + 图像特征轻融合，二分类 +2% F1）。

## 6. 11 类小类样本天花板
