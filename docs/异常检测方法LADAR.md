# LADAR：语言引导的双通道异常检测定位方法（2026-08-16）

**L**anguage-guided **D**ual-channel **A**nomaly detection for **R**adiology

## 动机（基线实测证据）

- 单层最近邻距离 + 正常库基线（233 例同域留出）：
  Pixel AUROC 0.967（病灶信号在）但 Image AUROC 0.31-0.41 **倒挂**、AUPRO 0.13、argmax 24%
- 倒挂根因：最近邻距离对"忙碌但正常"的解剖（肺尖骨/肝顶）敏感——它在正常分布内，但最近邻距离偏高
- 启发：CS-Flow 用**密度似然**替代最近邻（忙碌解剖在分布内 → 高似然 → 低异常）；
  f-AnoGAN 用**重建残差**定位（病灶是正常模型重建不出的结构）
- 我们的独特资源：707 份报告语言（位置词+尺寸）→ 替代像素掩膜作弱监督

## 方法总览

```
训练 (仅正常数据 + 报告语言, 无任何掩膜):
  正常切片 (良性组707 + 233无病灶层)
    ├─ 冻结 BiomedCLIP trunk → 多层 patch 特征 (块3/7/11/末层)
    │     → 各层拟合 GMM 密度 → patch 异常分 = -log p(x)      ← 通道① 密度 (CS-Flow式)
    └─ AE 重建 (224×224, 只学正常切片)
          → 残差图 |x - x̂|                                  ← 通道② 重建 (f-AnoGAN式)
  融合 head (小CNN, 可训练):
    输入 = 各层密度图(上采样) + 残差图 + 最近邻距离图
    输出 = 精细异常图 A (14×14) + 图级分数 s
  弱监督 (报告语言, 训练 head 用):
    L_region = 1 - Σ(A⊙R)/ΣA      R=报告位置词→3×3解剖区域
    L_size   = |diameter(A) - 报告长径| (smooth-L1)

推理:
  切片 → 双通道图 → 融合 head → A
    ├─ s (图级检测分)
    ├─ 病灶质心 → 区域词 (→ 报告注入)
    ├─ 直径估计 → 尺寸 (→ 报告注入, 无CSV数据集可用)
    └─ 热力图可视化
```

## 组件规格

| 组件 | 规格 |
|------|------|
| 多层特征 | trunk 块 [3,7,11,11] (ViT-B/16 共12块), 各 14×14×768 |
| GMM 密度 | 每层 128 成分, 对角协方差, 在 ~5 万正常 patch 上拟合; patch 分 = -log p |
| AE 重建 | 编码 3→64→128→256→512 对称解码, L2 损失, 正常切片 ~1 万张, GPU ~1 小时 |
| 融合 head | 输入 6 通道 (4密度+1残差+1NN距离) → Conv3×3×2 → 1 通道异常图; 参数量 < 1M |
| 图级分数 | head 输出图上的 top-k 均值 (k=20) |
| 弱监督损失 | L = L_region + 0.5·L_size, Adam 1e-3, 训练集=707代表层(train split) |

## 验证（233 例 ROI 金标准, 同域留出 100/133）

- Image-level AUROC / AP（含病灶层 vs 无病灶层）
- Pixel-level AUROC、AUPRO、argmax 命中
- 消融：NN基线 → +密度通道 → +重建通道 → +融合head → +语言弱监督

## 三向差异（答辩）

| 维度 | AnomalyCLIP | CS-Flow | f-AnoGAN | LADAR |
|------|-------------|---------|----------|-------|
| 监督 | 像素掩膜 | 仅正常 | 仅正常 | 仅正常 + 报告语言弱监督 |
| 定位机制 | DPAM自注意 | 流似然 | GAN残差 | 密度(GMM)+重建(AE) 双通道融合 |
| 主干 | 可改造CLIP | 自训特征 | 自训GAN | 冻结预训练BiomedCLIP |
| 临床资源 | 无 | 无 | 无 | 位置词+尺寸 (报告语言) |
| 域 | 工业 | 工业 | 眼科OCT | 纵隔占位CT |

**答辩句**：现有无监督方法单通道在解剖混杂的临床 CT 上失效（最近邻倒挂）；LADAR
以密度+重建双通道互补应对混杂，并首次以报告语言替代掩膜监督定位训练。

## 实施顺序

1. GMM 密度探针（换打分函数，验证"密度修倒挂"假设）— 几小时
2. AE 重建探针（第二通道基线）— 半天
3. 融合 head + 语言弱监督训练 — 1 天
4. 消融表 + 报告注入集成 — 半天
