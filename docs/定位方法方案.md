# LANAD 方案：语言引导的正常库异常检测定位（2026-08-16）

## 背景

- 现有 Path B（单层 patch + 正常记忆库最近邻）：检测 patch AUC 0.90（跨批次），
  定位弱（argmax 命中 8.8% 跨批次），热力图未经验证。
- 参考 AnomalyCLIP（Zhou et al. ICLR 2024）思路：patch 级定位 + 文本提示。
  关键差异：AnomalyCLIP 需要**像素级 GT 掩膜**训练（我们 707 例没有）；
  我们改用**报告语言弱监督**（位置词 + 尺寸）——原方法没有的资源。
- 定位产出直接接报告生成（质心/区域词/直径 → 文本注入），
  无 CSV 征象的数据集（如 BUSI）也能获得测量值。

## 方法（LANAD: Language-guided Normal-bank Anomaly Detection）

```
训练 (无掩膜):
  代表层 CT → 冻结 BiomedCLIP trunk
    → 多层 patch 特征 (第4/8/12层 + 末层, 不同感受野)
    → 各层与正常记忆库最近邻距离 → 多层距离图 {D4, D8, D12, Df}
    → 融合 head (轻量可学习加权/CNN) → 精细异常图 A (上采样到图像分辨率)
    → 弱监督损失 (无需掩膜):
        L_region = 异常质量须集中在报告指出的解剖区域
                   (报告位置词 → 3×3 区域标签 R; L = 1 - Σ(A⊙R)/ΣA)
        L_size   = 异常区直径 ≈ 报告长径 (平滑L1)
  可训练参数: 仅融合 head

推理:
  异常图 A →
    ├─ s_img (图级检测分)
    ├─ 质心 → 解剖区域词 ("右前纵隔"式描述)
    ├─ 直径估计 → 尺寸文本
    └─ 热力图可视化 (临床展示/报告附图)
```

## 与现有系统的接口

```
图像 ──→ LANAD ──→ s_img + 质心/区域词 + 直径估计 + 热力图
                        │                    │
                        ▼                    ▼
                  报告 findings JSON    报告生成器注入文本
                  (anomaly 字段, 已有)   ("病灶位于右前纵隔, 长径约18mm")
                                        ↑ 无 CSV 数据集也由此获得测量值
19维征象 ──→ 结构化分类器 ──→ 预测类别 (56.5%) ──→ 分类提示注入
图像+尺寸文本+征象词元 ──→ Qwen ──→ 报告 (CE 0.30 / ROUGE 0.4)
```

## 验证与指标（233 例 ROI 金标准，同域留出 100 建库 / 133 验证）

| 指标 | 数据 | 说明 |
|------|------|------|
| Image-level AUROC / AP | 含病灶层(阳性) vs 无病灶层(阴性, 同批) | 需补"正常图"来源 |
| Pixel-level AUROC | 异常图逐像素 vs ROI 掩膜 | 主指标 |
| AUPRO | 异常图连通域 vs ROI 连通域重叠 | 区域级指标 |

消融：单层 Path B（基线）→ +多层金字塔 → +L_region → +L_size

## 模块划分

1. `lanad/multiscale_features.py` — trunk 中间层 patch 提取
2. `lanad/fusion_head.py` — 距离图融合 + 弱监督损失
3. `lanad/region_labels.py` — 报告位置词 → 3×3 解剖区域标签（词典）
4. `lanad/metrics.py` — Image AUROC/AP、Pixel AUROC、AUPRO
5. `lanad/validate_roi.py` — 233 ROI 同域留出验证
6. 集成：anomaly_detect.py 的 Path B 输出换为 LANAD 产出

## 与原 AnomalyCLIP 的差异（答辩用）

| 维度 | AnomalyCLIP | LANAD |
|------|-------------|-------|
| 监督 | 像素级 GT 掩膜 | 报告语言弱监督（位置词+尺寸） |
| 定位机制 | DPAM v-v 自注意手术 | 多层 patch 金字塔 + 融合 head |
| 正常参照 | 可学习提示词 | 数据驱动正常记忆库 |
| 训练对象 | 提示词 | 融合 head（主干全冻结） |
| 额外产出 | 异常图 | 异常图 + 位置词 + 直径估计（直通报告） |

## 阶段计划

- 阶段0（半天）：metrics 管线 + 现 Path B 单层基线四指标
- 阶段1（1天）：多层金字塔 + 融合 head（无语言监督）
- 阶段2（1天）：+ 报告位置词/尺寸弱监督训练
- 阶段3（1天）：报告注入集成 + 全系统验收 + 消融表

## 风险与退路

- Pixel AUROC < 0.8：报告句里还有属性词可挖（边界/强化/密度）
- AUPRO 起不来：质心级定位已够报告用，论文报 AUROC 系 + 质心命中率
- 跨批次泛化差：同域验证为主，跨批次作鲁棒性副实验
