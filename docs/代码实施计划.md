## 阶段 1: 双流分类（核心改动，先验证准确率提升）

### 1.1 修改 `train.py` (extend_cfg)
```python
# 注册新配置项
cfg.TRAINER.ANOMALY_DETECT.LAMBDA_FUSION = 0.7   # 推理期融合权重
cfg.TRAINER.ANOMALY_DETECT.LAMBDA_ANNEAL = True  # 训练期 λ annealing
```

### 1.2 修改 `trainers/AnomalyDetect/anomaly_detect.py`
```
改动点 1: AnomalyCLIP.forward()
  现有: image → Path A(原图) / Path B / Path C
  改为:
    patch_features = ViT(image)          # 一次编码
    Path B: 记忆库距离 → anomaly map + s_img
    Path C: mask → masked_image
    双流分类:
      logits_masked = 分类头(masked_image 的 patch 特征)  # 病灶聚焦
      logits_full   = 分类头(原图 patch 特征)             # 全图兜底
      logits = λ·logits_masked + (1-λ)·logits_full
    注意: 分类头两次 forward 共享 prompt learner
          patch 特征只算一次，双流差异在特征是否经病灶加权

改动点 2: λ 计算 (forward 内)
  def _get_lambda(self, s_img):
      if self.training and LAMBDA_ANNEAL:
          lam = min(0.8, 0.5 + 0.3 * epoch / MAX_EPOCH)
      else:
          lam = LAMBDA_FUSION
      if s_img < 0.2:   # 掩膜不可信 → 回落
          lam = min(lam, 0.3)
      return lam

改动点 3: 掩膜覆盖率监控 (每 epoch)
  mask_ratio = mask.mean().item()
  if mask_ratio < 0.01 or mask_ratio > 0.9: print warning

改动点 4: forward 返回值保持兼容
  训练: (logits, loss_ce, loss_sccm, loss_kdsp, loss_consist, s_img)
  推理: (logits, s_img, anomaly_scores, concept_scores, masked_image)
```

## 阶段 2: 生成器接入（借鉴 Vinyals 层级 LSTM）

### 2.1 新增 `trainers/AnomalyDetect/report_generator_net.py`
```
class MLC(nn.Module):           # 9 征象多标签
  Linear(768 → 9) + Embedding(9 → 512) → top-k 语义特征

class CoAttention(nn.Module):   # 视觉 + 征象协同注意力
  W_v, W_a, W_fc → ctx [B, 512]

class SentenceLSTM(nn.Module):  # 句子主题 + 停止判断
  LSTM + W_topic + W_stop → topic [B, 512], p_stop [B, 2]

class WordLSTM(nn.Module):      # 中文词生成
  Embedding(vocab_size, 512) + LSTM + Linear → [B, vocab_size]
  sample(): 自回归逐词生成

class ReportGeneratorNet(nn.Module):
  MLC + CoAttention + SentenceLSTM + WordLSTM
  forward(image_features, captions, tags):  # teacher forcing
    循环句子: ctx → topic + p_stop → 逐词 CE
  generate(image_features, beam_k):          # Beam Search 推理
```

### 2.2 修改 `datasets/thymoma.py`
```
Dataset.__getitem__ 增加返回:
  - report_tokens: 该患者报告分句 → [[<start>词...<end>], ...]
  - tag_vector: 9 征象 one-hot
  - sentence_num / max_word_num（仿 Vinyals）
collate_fn: 句子维度 padding（batch 内句子数/词数对齐）
```

### 2.3 修改 `anomaly_detect.py` forward_backward
```
forward 输出增加生成分支:
  (logits, loss_ce, loss_sccm, loss_kdsp, loss_consist, s_img,
   loss_tag, loss_stop, loss_word)

loss = λ1·loss_ce + λ2·loss_tag + λ3·loss_word + λ4·loss_stop
       + λ5·loss_consist + λ6·loss_sccm + λ7·loss_kdsp
（权重: 1.0 / 0.5 / 1.0 / 0.5 / 0.5 / 0.75 / 0.75）
```

### 2.4 修改 `configs/trainers/AnomalyDetect/few_shot/thymoma.yaml`
```yaml

    GEN_MODE: true          # 启用生成分支

```
